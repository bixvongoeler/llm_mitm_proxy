# CS 163- Computational Geometry

## Course Overview

This course covers the design and analysis of algorithms for solving geometric problems. Cross-listed with MATH 181, it provides rigorous treatment of algorithmic techniques with formal complexity analysis including lower bound proofs.

## Key Topics

Based on the comprehensive lecture notes, the course covers:

**Foundational Algorithms:**
- Convex hull algorithms (multiple parts covering various approaches)
- "Marriage Before Conquest" convex hull technique
- Dynamic convex hulls and order decomposable problems

**Geometric Primitives:**
- Point inclusion in polygons
- Processing simple polygons into monotone regions
- Triangulating monotone regions
- Line segment intersection

**Higher Dimensions:**
- Convex hulls in 3D and higher dimensions (two-part coverage)

**Optimization:**
- Linear programming (with supplemental handwritten notes)

**Proximity and Partitioning:**
- Voronoi diagrams (with supplemental materials)
- Range searching
- Closest-pairs and farthest-pairs problems

**Advanced Techniques:**
- Duality transformations
- Topological sweep algorithms
- Point location (Kirkpatrick's and Edelsbrunner's algorithms)
- Rectilinear computational geometry
- Arrangements of lines

**Applications:**
- Data depth and computational statistics
- Lower bound proofs

## Prerequisites

While not explicitly stated, students should have strong backgrounds in:
- Algorithm analysis (Big-O notation, complexity classes)
- Discrete mathematics
- Basic linear algebra
- Proof techniques

The MATH 181 cross-listing suggests mathematical maturity is expected.

## Course Materials

The course provides extensive lecture notes in PDF format covering all topics, including both typed handouts and handwritten supplemental materials. A "Computational Geometry: A User's Guide" document provides introductory context.
