# CS 97- Senior Capstone Project I

## Course Overview

This is the first semester of a two-semester senior capstone sequence focusing on the planning, analysis, and design phases of a significant software engineering project. Students learn professional software development methodologies including requirements gathering, system design, and project management.

## Key Topics

- **Requirements Engineering**
  - Requirements analysis and elicitation methods
  - Prototyping techniques
  - Stakeholder communication

- **Software Design**
  - Design principles and architectural patterns
  - Designing for usability and user experience
  - Security considerations in design
  - Testability and maintainability
  - Performance optimization and scaling strategies

- **Project Management**
  - Project planning and scheduling
  - Cost and effort estimation
  - Team coordination and communication
  - Risk management

- **Documentation**
  - Writing effective technical documentation
  - Requirements specifications
  - Design documents

## Assignments/Projects

The course centers on a substantial capstone project that spans two semesters:
- **This semester (CS 97)**: Focus on requirements analysis, prototyping, and design documentation
- **Next semester (CS 98)**: Implementation and deployment

Students work in teams to develop a real-world software project from initial concept through detailed design specifications.

## Course Structure

This is part one of a two-course sequence (CS 97 and CS 98). The course emphasizes practical software engineering skills applied to a significant project, preparing students for professional software development work.

## Prerequisites

- Senior standing in Computer Science
- Completion of core CS curriculum including data structures, algorithms, and software engineering fundamentals
- Programming experience sufficient for a substantial development project
