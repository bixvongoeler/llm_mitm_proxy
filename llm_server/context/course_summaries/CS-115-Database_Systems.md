# CS 115 - Database Systems

## Course Overview
This course covers the fundamental concepts of database management systems (DBMS), providing students with both theoretical foundations and practical knowledge of how modern databases are designed, implemented, and managed.

## Key Topics
- **Data Models**: Relational model, object-oriented databases, and other data modeling approaches
- **SQL Query Language**: Comprehensive coverage of SQL for data definition and manipulation
- **DBMS Implementation Techniques**:
  - Storage and index structures
  - Concurrency control mechanisms
  - Recovery and fault tolerance
  - Query processing and optimization
- **Unstructured and Semi-structured Data**: Managing data beyond traditional relational formats
- **Scientific Data Collections**: Handling specialized data requirements for research applications

## Prerequisites
While not explicitly stated in the catalog description, database courses typically require:

- Familiarity with basic algorithms

Students should consult the department or course syllabus for specific prerequisite requirements.

## Course Context
This is an upper-level computer science elective that provides essential knowledge for:
- Backend and full-stack development
- Data engineering and analytics
- Systems programming
- Graduate studies in databases or data management

The course balances theoretical understanding of database internals with practical SQL skills that are directly applicable in industry settings.
