# CS 150-GT Graph Theory

## Course Overview
Introduction to graph theory covering trees, matchings, coloring, planar graphs, random graphs, and algebraic graph theory. This course does not require programming but has applications in computational geometry, computational biology, and algorithms.

## Key Topics
- **Fundamentals (Ch. 1)**: Graph definitions, isomorphism, walks/trails/paths, connectivity, bipartite graphs, Eulerian circuits
- **Trees & Counting (Ch. 2)**: Trees, distance metrics, Prüfer sequences, Huffman codes, graceful labeling
- **Matchings (Ch. 3)**: Hall's Theorem, König-Egerváry Theorem
- **Vertex Coloring (Ch. 5)**: Chromatic number χ(G), k-critical graphs, Brooks' Theorem, Mycielski's construction, chromatic polynomials
- **Planar Graphs (Ch. 6)**: Planar embeddings, Euler's formula, Kuratowski's theorem, 5-color theorem
- **Edge Coloring & Hamilton (Ch. 7)**: Vizing's Theorem, Hamiltonian cycles, Dirac's Theorem
- **Advanced Topics**: Network flows, connectivity, algebraic graph theory (eigenvalues, determinants), probabilistic method, random graph models
