# CS 140: Advanced Topics in Computer Architecture

## Course Overview

This course covers modern computer architecture, progressing from basic 5-stage pipelines to advanced out-of-order superscalar processors, multicore processors, and heterogeneous computing systems. Cross-listed with EE 156, it explores techniques to maximize single-thread performance within the constraints of memory technology, power consumption, and instruction-level parallelism.

## Key Topics

**Processor Fundamentals:**
- Computer architecture trends and dependability
- Performance measurement and reporting
- MIPS Instruction Set Architecture (ISA)
- MIPS datapath design

**Pipelining & Optimization:**
- MIPS pipelining implementation
- Pipeline hazards and resolution
- Branch prediction techniques

**Memory Systems:**
- Memory hierarchy introduction
- Virtual memory systems
- CUDA memory model for GPU computing

**Parallel & Heterogeneous Computing:**
- Loop-level parallelism
- GPU vs CPU architecture comparison
- Synchronization mechanisms
- CUDA programming fundamentals

**Modern Systems:**
- Warehouse-scale computers
- Mobile device architecture
- Current challenges in computer-system design

## Assignments & Labs

The course includes:
- Hands-on laboratory exercises
- Programming assignments (likely involving MIPS and CUDA based on lecture topics)
- Discussion of research papers on current architecture challenges

## Course Structure

Based on the Summer 2014 offering, the course follows an intensive schedule with lectures covering progressive topics from basic ISA concepts through advanced parallel computing architectures. The curriculum balances theoretical foundations with practical implementation through labs and assignments.

## Prerequisites

While not explicitly stated in the available materials, students should have:
- Strong foundation in digital logic and basic computer organization
- Programming experience (assembly language helpful)
- Understanding of basic processor concepts

**Note:** This course emphasizes both the theoretical underpinnings of modern processor design and practical considerations including power consumption and memory technology limitations. It culminates in discussions of cutting-edge research in the field.
