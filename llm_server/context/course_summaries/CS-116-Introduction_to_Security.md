# CS 116 - Introduction to Security

## Course Overview

This course provides a systems perspective on computer security, covering both host-based and network-based security concepts. Students learn about current vulnerabilities and protection measures for hosts and networks, including firewalls and intrusion detection systems.

## Key Topics

- Host-based security vulnerabilities and protections
- Network-based security vulnerabilities and protections
- Firewalls and their configuration
- Intrusion detection systems (IDS)
- Current security threats and countermeasures

## Assignments/Projects

The course emphasizes practical experience through hands-on programming projects that illustrate security principles. Specific project details are available on the course website at [cs116.org](https://cs116.org).

## Prerequisites

Based on the systems-level nature of the material, students should have:
- Strong programming background
- Understanding of computer systems and networking fundamentals
