# CS 150-CRY Cryptography

## Course Overview

An introduction to cryptography from historical ciphers through modern cryptographic systems, covering how codes and ciphers work and how they can be broken. The course uses a mathematical approach to prove properties about cryptographic systems.

## Key Topics

- **Historical cryptography**: Classical ciphers and their vulnerabilities
- **Symmetric (Private Key) cryptography**: Block cipher protocols
- **Asymmetric (Public Key) cryptography**: Modern encryption systems
- **Key exchange methods**
- **Hashing and message authentication**
- **Digital signatures**
- **Secret sharing protocols**
- **Digital cash systems**
- **Mathematical proofs of cryptographic properties**

## Prerequisites

- COMP 160 (Algorithms), COMP 170 (Theory of Computation), or graduate standing
- Any 100-level MATH course
- Permission of instructor accepted
- Core requirement: "mathematical maturity" — familiarity with reduction techniques

**Note:** This course is a variation of COMP 165 with revised prerequisites. Also cross-listed as DS 0153-01.
