# CS 167- Computational Biology

## Course Overview
This course addresses computational challenges in molecular biology, covering sequence alignment and comparison, genomic annotation, microarray data analysis, and proteomics. Students learn underlying computational techniques including dynamic programming, hidden Markov models, statistical analyses, and search and optimization procedures.

## Key Topics
- Sequence alignment and comparison
- Genomic annotation
- Microarray data analysis
- Proteomics
- Dynamic programming algorithms
- Hidden Markov models (HMMs)
- Statistical analysis methods
- Search and optimization procedures

## Course Format
Based on the additional course content (which appears to be from a related Statistical Bioinformatics course taught by Prof. Donna Slonim), the computational biology track at Tufts emphasizes:

- **Programming in R** for data analysis
- **Textbook**: *Modern Statistics for Modern Biology* by Susan Holmes and Wolfgang Huber
- **Weekly homework assignments** completed in R Notebook
- **Course project** involving substantial data analysis (either research-based or paper replication)
- **Class participation** including in-class exercises and discussions

## Grading Components
- Five homework assignments
- Course project (broken into several assignments)
- Class participation (including individual meeting with instructor)

## Prerequisites
- **CS 15** (Data Structures)
- At least one CS course numbered 100 or higher
- Basic familiarity with R for data analysis is expected
- Understanding of: variables, R data types (matrices, data frames), if/ifelse statements, for loops, vectorization, and writing functions

## Technical Requirements
- Computer with internet connection
- R and RStudio installation
- Gradescope account for submissions
