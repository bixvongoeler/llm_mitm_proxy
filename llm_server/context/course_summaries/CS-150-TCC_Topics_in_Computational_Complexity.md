# CS 150-TCC Topics in Computational Complexity

## Course Overview
This advanced course studies computational complexity in concrete computational models, focusing on techniques to prove lower and upper bounds on computational complexity. The main areas covered include decision trees, communication complexity, and Boolean circuit complexity, with brief discussions of proof complexity and algebraic computation models.

## Key Topics
- Decision trees and adversary arguments
- Certificate complexity
- Communication complexity
- Boolean circuit complexity
- Proof complexity (brief)
- Algebraic computation models (brief)
- Lower and upper bound proof techniques

## Prerequisites
