# CS 150-EP Epistemic Planning

## Course Overview
This advanced seminar explores automated logic-based deliberation that considers not only objective facts about an environment but also the beliefs and knowledge of agents within it. The course addresses problems like "how do I determine which cafeteria has pizza, get there, and ensure my friend knows where I'm going?"

## Key Topics
- **Classical Planning**: Foundational automated task planning techniques
- **Epistemic Logic**: Modal logic for reasoning about knowledge and belief
- **Kripke Semantics**: Possible worlds models for epistemic reasoning
- **Dynamic Epistemic Logic (DEL)**: Modeling how actions change knowledge states
- **DEL Planning**: Combining epistemic logic with automated planning
- **Bisimulation**: Equivalence relations for modal logic structures
- **Implicit Coordination**: Multi-agent planning without explicit communication
- **Conditional Planning**: Plans that branch based on observations
- **Belief Revision and Update**: How agents modify beliefs given new information
- **Planning Algorithms**: mA*, EFP, PG-Efp, RP-MEP approaches

## Prerequisites
- Programming proficiency required (C, C++, Java, or Python)
- Background in computer science, mathematics, or philosophy
- Interest in automated logic-based reasoning

## Assignments and Projects
- **Reading Responses** (20%): 100-500 word responses submitted as plaintext files for each assigned research paper
- **Homework Assignments** (40% total, 4 assignments at 10% each): Cumulative programming assignments building an epistemic planner
- **Midterm Exam** (20%): Take-home exam covering the first two-thirds of the course
- **Final Project** (20%): Improve your epistemic planner with new features or make another significant contribution; includes in-class presentation
- **Final Exam** (+10% extra credit): Non-cumulative take-home exam on post-spring-break material

## Course Structure
- **Format**: Online, synchronous, discussion-based seminar
- **Schedule**: Tuesdays and Thursdays, 4:30-5:45pm
- **Readings**: Research papers from key researchers including Bolander, van Ditmarsch, Baral, and others
- **Guest Speaker**: Christian Muise (epistemic planning researcher)
- **Collaboration**: Encouraged on all coursework except exams

## Grading Scale
Standard letter grades from A+ (97-110%) to F (0-59%), with the final exam providing opportunity to exceed 100%.
