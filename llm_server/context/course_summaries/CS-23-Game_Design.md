# CS 23 - Game Design

## Course Overview

This course covers the principles, design, and development of video games, combining technical implementation skills with interdisciplinary perspectives from economics, music, and psychology to create engaging interactive experiences.

## Key Topics

- Game structure and engineering fundamentals
- Game physics simulation
- 2D and 3D rendering techniques
- User interface design
- Sound and animation implementation
- Game testing methodologies
- Security considerations for online games
- Applications of economics in game design (game economies, player incentives)
- Music and psychology principles for player engagement

## Assignments/Projects

The course includes several major projects:
- **Game Design Documents**: Written specifications for game concepts
- **Interactive Fiction Game**: Development of a text-based narrative game
- **Team Game Project**: Building a functional game collaboratively with other students
