# CS 13: How Systems Work

## Course Overview

This course provides a foundational understanding of how computing systems work, covering the representation of information, CPU architecture, assembly language, and programming languages. It also introduces networking concepts including peering, packets, and the Internet, as well as algorithms and the fundamental limitations of computing.

## Key Topics

- **Information Representation**: Bits, bytes, and how data is encoded in computing systems
- **CPU Architecture**: Understanding how the central processing unit operates
- **Assembly Language**: Low-level programming concepts
- **Programming Languages**: Overview of how higher-level languages function
- **Networking**: 
  - Peering and Internet architecture
  - Packets and data transmission
- **Algorithms**: Computational problem-solving approaches
- **Computational Limits**: Fundamental limitations of what computers can compute
- **Information Theory**: Course references Shannon's seminal 1948 paper "A Mathematical Theory of Communication"

## Course Structure

This course is cross-listed as CS 13, CS 202, and DHP D292, indicating it serves multiple programs and student populations. The cross-listing suggests it may be designed as an introductory systems course accessible to students from different backgrounds.

## Prerequisites

No prerequisites are explicitly stated in the available materials. Given the introductory nature of the course covering fundamental concepts from bits and bytes upward, it appears designed for students new to computer systems.

## Additional Notes

The course emphasizes theoretical foundations alongside practical concepts, bridging the gap between abstract computing theory (information theory, computational limits) and concrete implementation details (CPU operation, networking protocols). The inclusion of Shannon's foundational information theory paper as reference material suggests an appreciation for the mathematical underpinnings of computing systems.
