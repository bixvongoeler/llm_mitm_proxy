# CS 165: Cryptography

## Course Overview
This course provides a mathematical introduction to cryptography, covering the principles behind cryptographic systems from historical ciphers through modern quantum cryptography. Students learn how cryptographic codes and ciphers work, how they can be broken, and how to prove security properties mathematically.

## Key Topics
- **Classical Cryptography**: Historical codes and ciphers, cryptanalysis techniques
- **Symmetric (Private Key) Cryptography**: Block ciphers, encryption modes
- **Asymmetric (Public Key) Cryptography**: RSA, key exchange protocols
- **Cryptographic Primitives**:
  - Hashing algorithms
  - Message authentication codes (MACs)
  - Digital signatures
- **Advanced Protocols**:
  - Secret sharing schemes
  - Digital cash systems
  - Key exchange mechanisms
- **Quantum Cryptography**: Introduction to quantum-resistant methods
