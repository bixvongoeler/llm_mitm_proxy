# CS 118: Cloud Computing

## Course Overview
This course covers cloud computing fundamentals, including cloud architecture, scalability, elasticity, and performance metrics (SLOs/SLAs). Students learn cloud programming models (MapReduce), persistent storage mechanisms, geo-distributed systems, cloud networking, and cloud security.

## Key Topics
- **Cloud Fundamentals**: Architecture, scalability, elasticity, service-level objectives/agreements
- **Distributed Systems Concepts**: Processes, threads, concurrency, IPC, RPCs, logical/vector clocks
- **Cloud Programming Models**: MapReduce and distributed abstractions
- **Storage Systems**: Key/value stores, cold storage, distributed databases
- **Cloud Networking**: Data center architecture, software-defined networking, middleboxes
- **Cloud Security**: Security considerations in cloud environments

- **Team Presentations (15%)**: Student-led presentations on course readings

## Prerequisites
- **Undergraduates**: CS 40 (Machine Structure & Assembly Language Programming) required
- **Recommended**: CS 111 (Operating Systems), CS 112 (Networking), or CS 117 (Internet-scale Distributed Systems)
- **Graduate Students**: A course in computer systems, networking, or distributed systems from any university

## Key Learning Outcomes
1. Articulate why cloud computing dominates modern software development
2. Understand and evaluate cloud technologies (virtualization, consensus protocols, distributed storage)
3. Use Infrastructure-as-a-Service (AWS EC2), Platform-as-a-Service (AWS EMR), and deployment frameworks (Kubernetes)
