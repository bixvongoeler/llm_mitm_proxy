# CS 11 - Introduction to Computer Science

## Course Overview

This introductory course covers the dual nature of computer science: foundational problem-solving methodologies drawn from engineering, mathematics, and scientific study, combined with practical application within modern computing systems. Students learn C++ programming as a tool for problem solving while exploring the Unix operating system environment.

## Key Topics

- Fundamental features of the C++ programming language
- Problem-solving methodologies and design principles
- Algorithm performance analysis (analytical and empirical assessment)
- Unix operating system fundamentals
- Engineering design principles applied to programming

## Course Structure

- **Lectures**: Regular class meetings covering programming concepts and problem-solving techniques
- **Labs**: Additional 2-hour weekly lab sessions (scheduled at first class meeting)
- **Readings**: Optional readings from the course textbook accompany each lecture

## Resources

The course provides:
- Detailed syllabus
- Weekly schedule with topics and assignments
- Coding style guide for proper C++ conventions
- Technical guide (CS11 Tech Guide) for development environment setup

## Prerequisites

- **Recommended**: High school algebra
- **No prior programming experience necessary**

This course is designed for students with no coding background, making it an ideal entry point into computer science at Tufts.
