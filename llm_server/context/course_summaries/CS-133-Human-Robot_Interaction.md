# CS 133- Human-Robot Interaction

## Course Overview
This interdisciplinary course explores human-robot interaction (HRI), examining challenges that arise when humans interact with robots. The course draws from psychology, human factors engineering, computer science, and robotics to address applications ranging from industrial manufacturing to socially assistive eldercare robots.

## Key Topics
- Fundamentals of human-robot interaction research
- Cognitive and social psychology as applied to robotics
- Robot design and behavior programming
- Conducting HRI studies and experiments
- Critical evaluation of real-world robot systems

## Course Structure
- **Format**: Primarily in-person and synchronous
- **Schedule**: Mondays feature lectures; Wednesdays feature interactive activities and discussions
- **Programming**: Python programming required for robot behaviors (students with less programming experience should expect additional workload)
- **Hands-on**: Direct experience working with robots

## Assignments and Projects

### Robot Implementation Assignments (25%)
- Due every other Wednesday
- Program robot behaviors and present code in class
- Extensions up to one week available upon request

### Project Milestones (30%)
- Due on alternate weeks from implementation assignments
- Build toward the final group project

### Group Project (25%)
- Teams of 2-4 students
- Complete an HRI-related research project
- Builds on individual project milestones

### Presentations (9%)
- Critical evaluation of a real-world robot
- Slides due in advance
- Includes quizzes on other students' presentations

### In-Class Activities & Design Reviews (11% combined)
- 12 total deliverables throughout semester
- Graded pass/attempted/fail
- Up to 5 can be completed independently if class is missed

## Grading Scale
Uses a 4.5-point scale corresponding to letter grades:
- **A+** (4.5): Above and beyond, creatively/technically impressive
- **A** (4): Meets all requirements with creativity or ambition
- **A/B** (3.5): Technically meets all minimum requirements
- **B** (3): Adequately demonstrates key skills but misses some requirements
- Lower grades reflect progressively incomplete work

## Prerequisites
Not explicitly stated, but Python programming proficiency is strongly recommended. Students should be comfortable with basic programming concepts.
