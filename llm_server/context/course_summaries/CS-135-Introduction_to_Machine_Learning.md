# CS 135: Introduction to Machine Learning

## Course Overview
An overview of methods whereby computers can learn from data or experience and make decisions accordingly. The course covers supervised learning, unsupervised learning, reinforcement learning, and knowledge extraction from large databases with applications to science, engineering, and medicine.

## Key Topics
- **Supervised Learning**: Regression (k-NN, linear, decision tree), binary and multi-class classification, logistic regression, neural networks
- **Unsupervised Learning**: Clustering, dimensionality reduction, recommendation systems
- **Model Evaluation**: Cross-validation, regularization, ROC curves, precision-recall curves, calibration plots
- **Neural Networks**: Gradient descent, automatic differentiation, deep learning fundamentals
- **Decision Trees**: Tree-based methods and explainability
- **Practical Skills**: Data preprocessing, hyperparameter tuning, train/test splitting

## Assignments and Projects
**Homeworks (8 total)**:
- HW0: Numerical Programming Fundamentals
- HW1: Regression, Cross-Validation, Regularization
- HW2: Evaluating Binary Classifiers, Implementing Logistic Regression
- HW3: Neural Networks and Gradient Descent
- HW4: Trees
- HW5: Explainability and Automatic Differentiation

**Projects (2 major)**:
- Project A: Classifying Text
- Project B: Movie Recommendations

Projects are open-ended case studies requiring significant programming, experimentation, and a 4-7 page written report. Students are assessed on technical sophistication, clarity of explanation, and experimental evidence.

## Course Structure
- **Lectures**: Twice weekly
- **Recitations**: Weekly TA-led sessions for hands-on practice
- **Exams**: Midterm and final exam
- **Late Policy**: 120 total late hours (5 days) across all assignments; maximum 48 hours late per individual assignment

## Prerequisites
- **Programming**: Comfortable with non-trivial programs (COMP 15 or equivalent); course uses Python with NumPy and matplotlib
- **Mathematics**: 
  - Probability: PDFs, CDFs, expectations, Gaussian distributions, Bayes theorem
  - Linear algebra: Matrix multiplication, inversion, least-squares solutions
  - Calculus: Gradient descent, learning rates, convex vs non-convex optimization
