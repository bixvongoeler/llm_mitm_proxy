# CS 169: Statistical Bioinformatics

## Course Overview
This data science elective covers computational methods and statistical analyses in bioinformatics and biomedical contexts. Students learn to assess hypotheses and data quality, visualize heterogeneous high-dimensional data, identify patterns and outliers, estimate probability through simulation, and present statistical results to specific audiences.

## Key Topics
- Statistical methods for bioinformatics and biomedicine
- Data quality assessment and visualization
- Pattern identification in high-dimensional data
- Probability estimation through simulation
- Analysis of genomics and medical data
- R programming for data analysis

## Prerequisites
- Basic familiarity with R for data analysis (not software development)
- Recommended preparation: R basics (variables, data types, matrices, data frames), if/ifelse statements, for loops, vectorization, and writing functions
- Biology background varies; course focuses on genomics and medicine examples but methods apply broadly
- Suggested resource: Rafael Irizarry's *R for Data Science* (Chapters 2-3)

## Course Materials
- **Textbook:** *Modern Statistics for Modern Biology* by Susan Holmes and Wolfgang Huber (Cambridge University Press) - available free online
- **Software:** R and RStudio with R Notebook for assignments
- Supplementary data sets and code examples available from textbook website

## Assignments & Projects
- **Five homework assignments** completed throughout the term

- Required readings
