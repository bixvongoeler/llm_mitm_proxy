# CS 15- Data Structures

## Course Overview
A second course in computer science that studies data structures and algorithms through major programming projects in C++. Students learn fundamental concepts including linked lists, trees, graphs, dynamic storage allocation, and recursion.

## Key Topics
- **Linked Lists**: Dynamic data structures with pointer-based node connections
- **Trees**: Hierarchical data organization and traversal algorithms
- **Graphs**: Network-based data structures and graph algorithms
- **Dynamic Storage Allocation**: Memory management with `new` and `delete`
- **Recursion**: Solving problems through self-referential function calls
- **C++ Templates**: Universal polymorphism for generic programming (implementing type-independent data structures like generic stacks)
- **Standard Template Library (STL)**: Using built-in C++ containers like vectors

## Assignments/Projects
- **Major Programming Projects**: The course emphasizes learning through substantial coding assignments
- **Debugging Practice**: Students are expected to use print statements extensively and learn Valgrind for memory error detection
- **File I/O**: Self-study modules cover file input/output operations

## Course Structure
- **Lectures**: All lectures are recorded and posted on Canvas via Echo360
- **Office Hours**: Robust schedule available; students must come with specific questions and complete the debugging procedure beforehand
- **Piazza**: Used for course announcements and Q&A
- **Submissions**: All homework and project submissions due by 11:59 PM on the specified date

## Development Environment
- **Remote Access**: Students work on department homework servers via SSH
- **Platform**: Linux/Unix command-line environment
- **Editor**: VS Code with SFTP extension officially supported
- **Compilation**: Projects compiled and tested on course servers

## Prerequisites
- CS 11 (Introduction to Computer Science) or equivalent
- Familiarity with basic programming concepts
- Prior exposure to Unix/Linux command-line recommended
