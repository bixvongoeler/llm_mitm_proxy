# CS 152-BDL Bayesian Deep Learning

## Course Overview

This graduate-level special topics course combines modern deep learning techniques with Bayesian statistical methods to estimate probabilities and make decisions under uncertainty. The course brings students to the forefront of this emerging research area through coding exercises, student-led discussions of recent literature, and an in-depth 2-month research project.

## Key Topics

**Unit 1: Bayesian Neural Networks**
- Gaussian Processes for regression
- Bayesian Neural Networks (BNNs)
- MCMC methods including Hamiltonian Monte Carlo
- Variational Inference for BNNs

**Unit 2: Deep Generative Models**
- Variational Autoencoders (VAEs)
- Function approximation with neural networks

**Technical Foundations**
- Automatic differentiation frameworks (PyTorch, TensorFlow)
- Probabilistic programming platforms
- Modern gradient-based training methods

## Assignments and Projects

**Homeworks (30%)**
- HW1: Gaussian Processes implementation
- HW2: Bayesian Neural Nets + Hamiltonian Monte Carlo
- HW3: Bayesian Neural Nets + Variational Inference
- HW4: Variational Autoencoders

**In-Class Participation (10%)**
- Post comments on assigned readings before each class (by 8am)
- Active participation in class discussions

**Discussion Leadership (10%)**
- Lead one class discussion (2-3 students per class)
- Prepare 20-30 minute presentation on assigned paper
- Meet with instructor beforehand to discuss strategy

**Research Project (50%)**
- Initial pitch presentation (5%)
- Three checkpoint reports (5%, 8%, 8%)
- Final presentation (8%)
- Final report (16%)

Projects span approximately 2 months and involve self-designed research. Ambitious projects could represent viable workshop submissions to conferences like NeurIPS or ICML.

## Course Structure

- **Format**: Mon/Wed 1:30-2:45pm lectures transitioning to student-led discussions after mid-October
- **First month**: Instructor-led presentations with hands-on activities
- **Remaining weeks**: Student-led paper discussions with roundtable format
- **Late policy**: 2 late days for homeworks; can skip comments for 4 readings without penalty

## Prerequisites

Required background:
- **Python programming**: numpy, matplotlib, scikit-learn
- **Probability theory**: Gaussian distributions, Bayes theorem
- **First-order optimization**: Gradient descent implementation
- **Linear algebra**: Matrix operations, least squares solutions
- **Machine learning basics**: Linear/logistic regression

**Formal prerequisite**: COMP 135 (Intro to ML), COMP 136 (Statistical Pattern Recognition), or instructor permission
