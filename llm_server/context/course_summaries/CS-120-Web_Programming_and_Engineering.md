# CS 120 - Web Programming and Engineering

## Course Overview

This course explores the engineering principles behind building complex web applications, covering the unique challenges of performance, scalability, usability, and security that distinguish web development from traditional software engineering.

## Key Topics

- Fundamentals of web engineering as an emerging multidisciplinary discipline
- Comparison of web engineering vs. traditional software engineering approaches
- Design patterns and information architecture
- Service-oriented architectures
- Content management systems
- Web application testing methodologies
- Modern web frameworks (Rails, Spring, Symfony)

## Assignments/Projects

Projects emphasize practical, industry-relevant applications including:
- Search functionality implementation
- Cloud computing integration
- Location-based services
- Mobile web development

## Prerequisites

Not explicitly stated in the available materials. Students should likely have foundational programming experience and familiarity with basic web technologies.
