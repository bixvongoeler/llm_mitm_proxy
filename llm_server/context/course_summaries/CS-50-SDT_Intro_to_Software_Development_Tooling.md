# CS 50-SDT Intro to Software Development Tooling

## Course Overview

This course teaches fundamental software development tools essential for maintaining reliable code in both industry and academia. Students learn four key tooling categories: version control, the Linux shell, build systems, and testing through hands-on projects and existing codebase exploration.

**Note:** The additional course content provided appears to be from a different COMP 50 course (focused on programming fundamentals using Racket/Scheme with the "How to Design Programs" curriculum). The summary below is based on the official description for the Software Development Tooling course.

## Key Topics

- **Version Control** - Industry-standard version control systems (likely Git)
- **Linux Shell** - Command-line proficiency and shell scripting
- **Build Systems** - Tools for compiling and managing code builds
- **Testing** - Techniques and frameworks for ensuring code reliability

## Learning Approach

The course takes a deep-dive approach to one industry-standard tool from each category, then surveys alternatives to help students understand when to choose one tool over another.

## Assignments/Projects

- Hands-on projects using each tooling category
- Exploration of existing codebases to understand real-world tool usage

## Learning Outcomes

By course completion, students will have:
- A robust toolset for managing complexity in future projects
- Skills to effectively ramp up on software projects in professional settings
- Understanding of why certain tools are preferred in different contexts

## Prerequisites

Not explicitly stated in the official description. Students likely benefit from basic programming experience given the focus on professional development practices.
