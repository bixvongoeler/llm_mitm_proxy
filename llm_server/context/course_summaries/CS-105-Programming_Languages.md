# CS 105 - Programming Languages

## Course Overview

This course covers the principles and application of computer programming languages, emphasizing ideas and techniques relevant to practitioners while building intellectual rigor through foundations in abstract syntax, lambda calculus, type systems, and dynamic semantics. The course uses case studies reinforced by programming exercises to prepare students to read professional programming language literature.

## Key Topics

- Abstract syntax and language representation
- Lambda calculus fundamentals
- Type systems (static and dynamic typing)
- Dynamic semantics (operational semantics)
- Programming language design principles
- Case studies of various programming paradigms

## Prerequisites

Based on the course level (100-level graduate/advanced undergraduate), students should have:
- Strong programming background (typically CS 15 Data Structures or equivalent)
- Familiarity with multiple programming languages
- Mathematical maturity for formal reasoning

## Course Structure

This is an advanced course that balances theoretical foundations with practical application. Students engage with:
- Programming exercises implementing language concepts
- Case study analysis of real programming languages
- Reading and understanding professional PL literature
