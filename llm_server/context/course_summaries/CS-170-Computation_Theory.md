# CS 170: Computation Theory

## Course Overview
An introduction to the theoretical foundations of computer science, exploring models of computation including Turing machines, pushdown automata, and finite automata, as well as formal languages and important decidability problems like the halting problem.

## Key Topics
- **Models of Computation**: Turing machines, pushdown automata, finite automata
- **Formal Languages & Grammars**: Context-free languages, regular sets, context-free grammars
- **Undecidability**: The halting problem, language equivalence theorems
- **Complexity Theory**: Diagonalization arguments, nondeterminism
- **Additional Topics**: Information theory, time vs. space complexity, complexity classes (P, NP, etc.)
