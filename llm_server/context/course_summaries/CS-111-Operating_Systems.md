# CS 111 - Operating Systems

## Course Overview

This course covers fundamental issues in operating system design, focusing on concurrent processes and their management including synchronization, sharing, deadlock, and scheduling. It also examines relevant hardware properties of both uniprocessor and multiprocessor computer systems.

**Cross-listed as:** EE 128

## Key Topics

Based on the official description, the course covers:

- **Concurrent Processes**: Understanding how multiple processes execute and interact
- **Synchronization**: Mechanisms for coordinating process execution (mutexes, semaphores, monitors)
- **Resource Sharing**: Managing shared resources between processes
- **Deadlock**: Detection, prevention, and recovery from deadlock conditions
- **Process Scheduling**: Algorithms and policies for CPU scheduling
- **Hardware Considerations**: Architecture-specific issues for uniprocessor and multiprocessor systems

## Prerequisites

Students should have a strong foundation in:
- Systems programming (typically C)
- Data structures
- Computer organization/architecture fundamentals

*Note: Specific prerequisites should be confirmed with the department, as this is a 100-level advanced course typically requiring prior coursework in computer systems.*

## Additional Information

As a core systems course, CS 111 provides essential knowledge for students interested in systems programming, kernel development, distributed systems, or any area requiring deep understanding of how software interacts with hardware at the operating system level.
