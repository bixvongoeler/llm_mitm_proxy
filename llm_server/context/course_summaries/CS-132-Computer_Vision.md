# CS 132 - Computer Vision

## Course Overview
An introduction to low and intermediate levels of classic and modern computer vision, teaching students how to design algorithms that process visual scenes to automatically extract information. The course covers fundamental principles and important applications including image formation, processing, feature detection and matching, image segmentation, and multiple views, with basics of machine learning and deep learning for computer vision.

## Key Topics
- **Image Formation**: Human vision, optics, physics, cameras, perspective projection, pinhole camera model, digital imaging, color spaces, sampling
- **Image Processing**: Convolution filters, edge detection, frequency domain, Fourier Transform, histograms, non-linear filters (median, bilateral), image pyramids
- **Feature Detection**: Interest points, corners (Harris), blobs, FAST, multiscale detection, edges & contours, binary image analysis, Hough & Hu Moments
- **Geometric Transforms**: Feature matching, least squares optimization, image alignment, RANSAC
- **Image Stitching**: Panoramas, cylindrical coordinates, bundle adjustment, blending
- **Tracking**: Motion estimation, CONDENSATION, particle filtering, Kalman filtering, correlation filters, optical flow (Lucas-Kanade, Shi-Tomasi)
- **Multi-View Geometry**: Camera calibration, stereo vision, depth/disparity, epipolar geometry, essential/fundamental matrices, triangulation, pose estimation, structured light, large-scale reconstruction
- **Machine Learning for Vision**: Linear models, regression and classification, logistic regression, CNNs, famous architectures, backpropagation, training practices
- **Object Detection**: Viola-Jones, R-CNN variants, YOLO, SSD
