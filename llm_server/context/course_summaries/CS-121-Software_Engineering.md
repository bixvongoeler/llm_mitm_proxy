# CS 121 - Software Engineering

## Course Overview
Software engineering covers all aspects of software production from early product concepts through design, implementation, and post-delivery maintenance. The course focuses on core principles that enable building large-scale software systems, with emphasis on the coding side of software engineering including abstraction, modularity, architecture, specification, testing, and debugging.

## Prerequisites
- CS 15, graduate standing, or instructor consent

## Key Topics
- Java programming (classes, objects, inheritance, interfaces, delegation, generics, runtime)
- Abstract data types, modularity, and information hiding
- Design patterns
- Software architecture
- Object-oriented refactoring
- Testing
- Concurrency
- Debugging

## Assignments and Projects
The course includes five programming projects in Java:
- **Project 1**: Java ADTs and the Adapter Pattern
- **Project 2**: Design Patterns in Java
- **Project 3**: A Unit Testing Framework
- **Project 4**: Java on Rails
- **Project 5**: Parallel Regexp Matching

Additionally, there are reading assignments covering seminal papers:
- Wirth's "A Brief History of Software Engineering"
- Parnas's "On the Criteria To Be Used in Decomposing Systems into Modules"
- ACM Code of Ethics
- Brooks's "No Silver Bullet"
- Li, Ko, and Zhu's "What makes a great software engineer?"

## Course Structure

**Grading Breakdown:**
| Component | Weight |
|-----------|--------|
| Projects/homework | 50% |
| Readings | 10% |
| Midterm | 20% |
| Final | 20% |

**Late Policy:** Students receive two late tokens allowing 24-hour extensions each (can be combined for 48 hours on one project). Late tokens cannot be used for reading assignments.

**Important:** Students who do not make a good-faith attempt on all projects may fail regardless of other scores. Grades of D+, D, or D- are not awarded in this class.

## Format
Projects are submitted electronically by 11:59pm on due dates. Reading assignments are due at the start of class. The course includes both midterm and final exams. Past exams (with solutions) from Fall 2019 through Fall 2025 are available for study.
