# CS 20 Web Programming

## Course Overview

An introduction to techniques, principles, and practices of writing computer programs for the World Wide Web. The course covers both client-side and server-side web development, exploring browser and server capabilities, limitations, and security considerations.

## Key Topics

- Server and browser capabilities and limits
- Media types, handlers, and limitations
- Web programming languages and techniques
- Web security, privacy, and commerce
